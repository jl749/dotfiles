# NIXOS RUST Template

## NIX
To update flake: `nix flake update` (never with sudo, it writes flake.lock)

To start bash shell: `nix develop`

## cargo
```
To create project: `cargo new {project_name}`
To build project: `cargo build`
To build&run project: `cargo run`
To check (no executable): `cargo check`
```
